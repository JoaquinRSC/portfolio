# Joaquín Rossi — Portfolio

My personal developer portfolio. Built with **Vue 3 + Quasar + Vite**, with a
dark, terminal-inspired design and **interactive in-page demos** of my projects
that run on sample data — no backend and no real accounts.

**Live:** https://joaquinrossi.vercel.app

## Highlights

- **Single-page site** — hero, about, projects, stack, education and contact
  sections, fully bilingual (EN / ES) with a lightweight native-Vue i18n.
- **Project cards** — a one-line pitch plus a few technical highlights per
  project, and a **case study** dialog (problem, architecture, key decisions,
  next steps) for Cuidauto.
- **Embedded project demos** — cards open the real app in-page (in an iframe),
  running on fake data so visitors can actually try it:
  - **CS2 Skin Tracker** — the Vue 3 + Quasar PWA built with a `DEMO_MODE` flag
    that loads sample data and skips every API call.
  - **CSFloat Buy Orders** — the full automation dashboard, with a mock layer
    that intercepts `fetch`/`EventSource` to simulate the live scan and
    opportunities flow.
- **Screenshot lightbox** — portrait (mobile) projects render as a phone trio
  and open a device-framed gallery.
- **Details** — installable PWA, Open Graph / Twitter previews, Vercel Web
  Analytics, scroll reveals that honor `prefers-reduced-motion`, a typewriter
  hero, hero stats derived from the project data, and vendored stack icons.

## Tech

- Vue 3 (`<script setup>`), Quasar, Vite, SCSS
- Deployed on Vercel

## Development

```bash
npm install
npm run dev      # dev server
npm run build    # production build -> dist/
npm run preview  # preview the production build
```

## Content

All copy is data-driven, so most updates never touch a component:

| What | Where |
| --- | --- |
| Projects (pitch, highlights, case study, tags, demo/screenshots) | `src/data/projects.js` |
| Page copy in both languages | `src/data/i18n.js` |
| Stack | `src/data/skills.js` (icons in `public/icons/tech/`) |
| Education | `src/data/education.js` |
| Email, CV, GitHub, LinkedIn | `src/data/contact.js` |

## Project demos

The demos are self-hosted under `public/demos/<name>/` and embedded from the
project cards, so there is no separate deployment per demo. They run on bundled
sample data only; the CSFloat demo is generated by
`scripts/build-csfloat-demo.cjs` (with its mock in `scripts/csfloat-demo-mock.js`).
